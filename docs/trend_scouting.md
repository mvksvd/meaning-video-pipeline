# Поиск трендов: пул источников → парсинг → судья → карточка-идеи

Как конвейер сам находит темы, а не ждёт, пока их принесёт человек.
Вся система заточена под наш бренд (Айплюс, образование, Казахстан) — но
методика переносима: меняешь пул источников и профиль бренда, остальное
работает как есть.

## Схема слоя

```
ПУЛ ИСТОЧНИКОВ (sources.json — собираешь один раз под нишу)
 │  Apify (apify/instagram-scraper) ── свежие посты аккаунтов,
 │  пул API-ключей с ротацией (упёрся в месячный лимит → следующий ключ)
 ▼
ДЕДУП (seen.json) ── каждый пост оценивается один раз
 ▼
СУДЬЯ (Claude CLI) ── чек-ядро виральности из 4 обязательных пунктов:
 │   герой + мостик к бренду + пересказываемый факт + «наши»
 │   (+ дедуп по героям против уже взятых тем)
 ▼
КАРТОЧКИ-ИДЕИ (ideas/INBOX.md + idea_NNN.json)
 ▼
ЧЕЛОВЕК выбирает карточку → meaning_writer.py --topic "..." → дальше
обычный конвейер: сценарий → озвучка → раскадровка → генерация → сборка
```

## 1. Пул источников — главный актив

Скаут ищет не «по всему интернету», а по СПЕЦИАЛЬНО СОБРАННОМУ пулу
аккаунтов. Наш боевой пул — **107 Instagram-аккаунтов + 9 Telegram-каналов +
15 новостных сайтов**, собирали и пополняли вручную. Категории:

| Категория | Наши примеры | Что даёт |
|---|---|---|
| Новостники (страна/город/бизнес) | bes.media, kazpress, almaty_news, Digital Business KZ | свежие события и героев каждый день |
| Организации ниши | ~20 аккаунтов школ сети НИШ по городам | победы учеников, олимпиады — герои «из первых рук» |
| Блогеры ниши | образование-блогеры, преподаватели | какие форматы/темы заходят нашей ЦА |
| Конкуренты и смежные бренды | другие учебные центры | их удачные механики |

Как собирать свой пул: иди от вопроса «где раньше всех появляются ГЕРОИ моей
ниши». Подпишись глазами на 10-15 кандидатов, неделю смотри, кто реально даёт
темы — тех в пул. Пул живой: слабые источники выкидываем, новые добавляем.

## 2. Парсинг: Apify и деньги

- Актор: `apify/instagram-scraper` (режим Pay per result, **~$0.0027 за пост**).
- Объём: 10-30 свежих постов с аккаунта за прогон (`--limit-posts`).
- Ритм: новостников имеет смысл смотреть ежедневно, остальное — раз в неделю
  (у нас так и настроено: новостные источники чаще, школы/блогеры реже —
  их лента меняется медленно, каждый день жечь деньги незачем).
- Прогон 30 новостных аккаунтов × 10 постов ≈ 300 постов ≈ **$0.8**. Месяц
  ежедневного скаутинга ≈ $20-25.

**Ключи пулом.** Один аккаунт Apify упирается в месячный лимит тарифа, поэтому
мы держим НЕСКОЛЬКО аккаунтов (у нас 6) и кладём все ключи в
`APIFY_API_TOKENS=key1,key2,...` через запятую. Скрипт ротирует сам: ключ
упёрся в месячный лимит — помечается exhausted (файл
`~/.trend-scout/apify_state.json`) и до конца месяца не используется; 429
(троттл) — просто пробуем следующий ключ, не выжигая.

**Правило денег: цена считается ДО запуска.** Скрипт печатает план
(аккаунты × посты × $0.0027) и отказывается работать дороже `--max-cost`
(дефолт $1 за прогон). Это защита от «молчаливой лавины», на которую мы
однажды напоролись сами.

## 3. Судья-классификатор

Каждый новый пост оценивает Claude (модель sonnet — дёшево и достаточно) по
чек-ядру из 4 ОБЯЗАТЕЛЬНЫХ пунктов — оно выведено из разбора наших хитов
(ролик про Яндекс: 273К просмотров, шер-рейт 3%):

1. **Герой** — конкретный человек/маленькая команда, не компания и не министерство.
2. **Мостик к бренду** — героя можно честно связать с темой бренда.
   Это главный фильтр: без мостика тема не наша, каким бы вирусным ни был пост.
3. **Пересказываемый факт** — цифра/рекорд/«первый», который зритель перескажет за ужином.
4. **«Наши»** — герой свой для аудитории, повод для гордости.

Плюс-фактор: «есть о чём спорить в комментариях» (повышает confidence).

Профиль бренда судья берёт из `docs/brand_profile.md` — там «кто мы, что
считается мостиком, эталоны». Под другую нишу переписываешь только этот файл,
промпт судьи не трогаешь.

Защиты: максимум 40 классификаций за прогон (лавина CLI-вызовов), порог
`confidence >= 6` для заведения карточки, дедуп по героям (список уже взятых
тем подставляется в промпт — судья ставит `duplicate=true`).

## 4. Карточки-идеи

Кандидаты падают в `ideas/`:
- `idea_NNN.json` — герой, мостик, факт, confidence, ссылка на источник;
- `INBOX.md` — сводка для быстрого просмотра глазами.

Дальше решает человек: понравилась карточка → запускай производство
(`meaning_writer.py --topic "<герой и суть>"`). Автоматически в производство
карточки НЕ уходят — отбор тем остаётся за человеком, это сознательное решение.

## 5. Крон

```
# ежедневный скаут по новостникам (утро — темы свежие к дневному планированию)
45 8 * * * cd <репо> && .venv/bin/python scripts/trend_scout.py --limit-posts 10 >> ~/trend_scout.log 2>&1
```

У нас в проде поверх этого живёт второй прогон — «архивный охотник» раз в
неделю: ходит не по свежим постам, а по СТАРЫМ материалам (вечнозелёные
герои, у которых нет срока годности) тем же судьёй. Логика та же, меняется
только источник контента.

## Наши грабли (уже пройдены — не повторяй)

1. **Молчаливая ротация ключей без потолка** однажды сожгла нам 3 ключа за
   ночь (~$9). Отсюда правило «цена ДО запуска» и `--max-cost`.
2. **Судья без списка взятых тем** заводит одного героя по три раза (каждый
   новостник напишет о нём по-своему). Дедуп по героям обязателен.
3. **Слишком умный фильтр = пустой inbox.** Порог confidence 6/10, не 9/10:
   лучше 5 карточек на выбор человеку, чем 0 «идеальных».
4. **Пост без caption не классифицируем** — по одной картинке судья фантазирует.
