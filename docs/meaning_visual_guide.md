## 1. ЦИФРЫ ЭТАЛОНА (как реально смонтированы залетавшие креативы)

- План: медиана **2.5с**, средняя 2.8с → на минутный ролик 20-24 плана
- Доля б-роллов 67% (спикер 33%). У нас спикера НЕТ → б-роллы 100%,
  разнообразие приёмов должно компенсировать отсутствие лица
- Приёмы б-роллов эталона: прямая иллюстрация 50%, атмосфера 20%,
  **метафора 19%**, типографика 5%, контраст 5%
- Источники эталона: живая съёмка 65%, сток 29%, **ИИ всего 4%** —
  доверие держится на реальности. Наш формат: ИИ-кадры анимируем (Kling),
  но миксуем со стоками/архивом, полного ИИ-слопа не допускаем

## 2. НАШ БАЛАНС ПРИЁМОВ (формат без спикера, на минуту ≈ 20 планов)

- метафоры — 25-30% (5-6 планов): по ОДНОЙ яркой на звено цепочки мостов
- прямая иллюстрация — 30-35%: конкретные слова заземляем буквально
- атмосфера/состояния — 20-25%: эмоции героев кадра без прямой связи со словом
- контраст — 8-10%: проблема↔решение, 99%↔1%
- типографика — ключевое слово фразы выносится НА кадр (не отдельным планом)

## 3. СЛОВАРЬ МЕТАФОР (проверенные образы из разборов + переводы смыслов)

**Путь/рост**: лестница вверх (+свет в конце = цель); сломанная лестница =
препятствие; перекрёсток = конфликт подходов; две дороги: толпа по одной,
один человек по другой = «этой дорогой идут не все»; длинный коридор =
образовательный путь; широкое поле = открытое будущее
**Знания/система**: книга = система (закрывается = не работает); гора книг =
объём; стопка учебников = фундамент; формулы на доске = сильная база;
лампочка над головой = инсайт; мозг 3D = мышление; сборка механизма = возможности
**Давление/тревога**: красный свет = сигнал тревоги/поздно; контровая лампа
над ребёнком (допрос) = давление; жёсткие тени на лице = эмоциональная
загрузка; хаос мазков краски = перегруз мозга; рой задач = стресс;
кукловод/нити = система лишает самостоятельности; негатив-инверсия = угроза
**Контроль/забота**: красная ручка = надзиратель; рука кладёт монету в банку =
инвестиция; рукопожатие = добровольность; старший брат = ментор
**Среда/конкуренция**: полупрозрачные ученики появляются за спиной =
невидимые конкуренты; коридор из рук = поддерживающая среда; поднятая рука =
уверенность/«на голову выше»; телефон на фоне стопки учебников = прокрастинация
**Потенциал**: тень орла над ребёнком = скрытая сила; свет из окна на тетрадь =
надежда; «Мыслитель» = логика
**Поп-культура** (работает мощно, брать дозированно, 1 на ролик максимум):
супергерой = одарённый; костюм/броня = система, которая усиливает;
мем-цитата = ироничная мудрость

## 4. ФИРМЕННЫЕ ПРИЁМЫ МОНТАЖА ЕРНАЗАРА (переносим в формат)

1. **Вспышка-инверсия** 0.1-0.2с (негатив, иногда + глитч) на акцентном слове —
   и как переход между смысловыми блоками. Наш аналог перехода между ЗВЕНЬЯМИ
   цепочки мостов: каждое новое звено = вспышка
2. **Типографика-дубль**: ключевое слово фразы крупно на кадре (2-4 слова макс)
3. **Наложение/коллаж**: полупрозрачные кадры поверх (конкуренты за спиной),
   коллажи из нескольких кадров
4. **Контраст-пара подряд**: расслабленный ребёнок с телефоном → усердные
   конкуренты; грустная мама → ребёнок с потенциалом
5. **Доказательства-скриншоты**: интерфейс приложения, документы с баллами —
   только реальные (антифейк)
6. **Свет и цвет как эмоция**: тёплый свет = решение/надежда, красный = тревога,
   ч/б = проблема

## 4б. МЕХАНИКИ ИЗ СКИЛЛА HIGGSFIELD faceless-channel-video (разбор 04.08)

- **Стиль-формула байт-в-байт**: один паспорт 80-100 слов (линия/поверхность ·
  шейдинг · палитра · ОДИН фирменный акцент · фон · тайминг движения · рендер)
  вставляется без изменений в каждый промпт ролика + PALETTE LOCK отдельной
  строкой в видео-промптах. Формула не переформулируется никогда.
- **Сквозной объект = отдельный ассет**: повторяющийся предмет (наша банка)
  не генерится заново — повторные кадры делаются micro-variation: «keep the
  reference EXACTLY, change ONLY {одна деталь}», референс — предыдущий кадр
  и ТОЛЬКО он.
- **Грамматика движения**: план не длиннее 2.5с («3-5с читается как слайдшоу»);
  каждый бит — видимое действие с landing verb (snaps into place, stamps down,
  drops with a bounce, settles); РОВНО одно движение камеры на план («two moves
  in one cut reads as AI soup»); impact-бит примерно каждые 3 секунды; финальный
  кадр «settled, не frozen» (микродвижение остаётся).
- **Вариативность**: соседние планы всегда разной крупности/угла; два крупных
  плана подряд запрещены; ритм типа W M W C W W M C.
- **Channel DNA**: стиль-паспорт + голос + акцент сохраняются JSON'ом, чтобы
  ролик №2 выглядел тем же «каналом» (наш аналог — этот файл + карта мостов).
