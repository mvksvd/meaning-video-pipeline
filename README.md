# Meaning Video Pipeline — конвейер смысловых вертикальных видео

Полная система «от тренда до готового ролика»: поиск тем по своему пулу
источников → судья-отбор → сценарий по карте смысловых мостов → озвучка →
раскадровка в нуар-стиле → ИИ-кадры + анимация → автосборка с сабами и
музыкой → чеки качества. Видео 60-75 сек, 9:16, без спикера.

Проверена в бою: пилот «Богатые и бедные» собран этим конвейером целиком,
темы наших хитов (Яндекс — 273К просмотров) найдены этим же скаутингом.

Система заточена под наш бренд (Айплюс — образование, Казахстан), но
переносима: свой пул источников (`sources.json`) + свой профиль бренда
(`docs/brand_profile.md`) — и тот же конвейер работает на другую нишу.

## Как устроен флоу

```
ПОИСК ТЕМЫ (докладно: docs/trend_scouting.md)
 │ sources.json ───────── СВОЙ пул источников (у нас 107 IG-аккаунтов:
 │        │               новостники, школы НИШ, блогеры ниши)
 │ trend_scout.py ─────── Apify-парсинг постов (пул ключей с ротацией,
 │        │               цена считается ДО запуска) → дедуп →
 │        │               СУДЬЯ (Claude): герой + мостик к бренду +
 │        │               пересказываемый факт + «наши»
 ▼        ▼
КАРТОЧКИ-ИДЕИ (ideas/INBOX.md) → человек выбирает тему
 │
 ▼
ТЕМА
 │ meaning_writer.py ──── пишет сценарий по карте мостов (docs/meaning_bridges.md)
 │        │
 │ meaning_check.py ───── 3 чекера: прямолинейность (продажа не раньше 80%
 │        │               хронометража), кивабельность каждого перехода, стиль
 ▼        ▼
ОДОБРЕННЫЙ ТЕКСТ
 │ TTS (ElevenLabs) ───── голос + akцент-словарь + break-паузы + atempo 1.08
 │ phrase_times ───────── тайминги фраз (Gemini, с жёсткой рамкой длительности)
 │ shotlist (в factory) ─ раскадровка 14-20 планов по нуар-формуле и словарю
 │                        метафор (docs/meaning_visual_guide.md)
 │ Higgsfield CLI ─────── кадры (nano_banana) → анимации (kling3_0_turbo,
 │                        3-6 сек = жизнь плана + 1с, звук off)
 ▼
СБОРКА (meaning_assemble / meaning_factory)
 │ планы стык-в-стык по фразам · вспышки-инверсии 0.12с на смысловых звеньях
 │ нижние сабы фразами (ass), кодовое слово золотом · трек с дропа, vol 0.16
 ▼
ЧЕКИ → joint_check.py (стыки/ритм) → готовый mp4
```

Ночной автозавод: `meaning_factory.py` крон-ом прогоняет одобренные карточки
до готового ролика (параллельная генерация, до 2 роликов за прогон,
предохранитель по кредитам).

## Требования

- Linux/macOS, Python 3.11+, ffmpeg/ffprobe
- **ElevenLabs API** (озвучка) — ключ в .env
- **Google Gemini API** (тайминги фраз, чеки-анализ) — ключ в .env
- **Apify** (скаут трендов) — ключи пулом в `APIFY_API_TOKENS`
  (несколько аккаунтов Apify, скрипт ротирует сам; ~$0.0027/пост)
- **Higgsfield CLI** (кадры и анимация Kling) — `npm i -g higgsfield`,
  авторизация `higgsfield auth`, тариф с кредитами (~50-70 кредитов на ролик)
- **Claude CLI** (сценарист и раскадровщик) — авторизованный `claude`
- Библиотека музыки: папка mp3 (см. MUSIC_DIR в скриптах)

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать ключи
# поправить пути в начале скриптов: у нас всё лежит от /home/MaksVideo —
# замените Path.home()-константы под свой дом (см. раздел «Пути» ниже)
```

## Пути, которые надо адаптировать

Скрипты писались под боевой сервер и берут корень от `Path.home()`:
- `~/meaning_factory_work/`, `~/meaning_pilot_assets/` — рабочие папки (создаются)
- `~/music_library/*.mp3` — треки
- `~/.aiplus-factory/tts_pronun.json` — словарь ударений (акуты для TTS,
  формат: {"слово": "сло́во"}; работает только с eleven_multilingual_v2)
- `meaning_factory.py` дополнительно пишет статусы в Postgres (таблица
  story_videos) — для standalone-запуска этот блок можно закомментировать
  и звать функции напрямую (tts → phrase_times → shotlist → gen_shot → assemble)

## Порядок запуска вручную (без завода)

```bash
# 0. Скаут тем (опционально — можно прийти и со своей темой)
cp sources.example.json sources.json   # заполнить своим пулом аккаунтов
python scripts/trend_scout.py --limit-posts 10   # → ideas/INBOX.md

# 1. Сценарий (создаст текст + прогонит чекеры)
python scripts/meaning_writer.py --topic "Дисциплина: ..." --route "В2"

# 2. Озвучка (голос/настройки в gen_voice_v7.py: stability 0.75, паузы, x1.08)
python scripts/gen_voice_v7.py

# 3. Тайминги фраз
python scripts/phrase_times_sergey.py

# 4-6. Раскадровка + генерация + сборка — самый простой путь: meaning_factory
python scripts/meaning_factory.py --card <ID>   # или адаптировать main()

# 7. Чек стыков
python scripts/joint_check.py out.mp4   # нужен out.mp4.shots.json (пишет сборщик)
```

## Ключевые know-how (усвоены итерациями с владельцем)

1. **Карта мостов** (docs/meaning_bridges.md): продукт максимум в одном
   последнем звене; каждый ТРЕТИЙ ролик совсем без продукта; перевёртыш
   обязателен для социально-острых тем.
2. **Нуар-формула** вставляется в каждый промпт БАЙТ-В-БАЙТ (одна формула на
   ролик — это весь механизм консистентности стиля). ИИ-лица крупно запрещены:
   силуэты, спины, руки, среды.
3. **Kling-промпт = ЖЕСТ**: одно движение + одно движение камеры (или static).
   Два действия = брак. Длительность = жизнь плана + 1с (не 6с всем подряд).
4. **Реальные футажи 25fps НЕ замедлять** — рассыпаются; тянуть можно только
   почти-статичные ИИ-анимации (замок в сборщике).
5. **Тайминги фраз от Gemini валидировать рамкой длительности** (иначе
   галлюцинирует хронометраж) — 3 ретрая, фейл = стоп.
6. **Микроплан < 1.2с и план > 9с = брак ритма** (joint_check).
7. Музыка: старт с дропа (авто-поиск по RMS), не с вступления.

## Структура

```
scripts/   весь код конвейера (trend_scout — поиск тем; writer/check — сценарий;
           factory/assemble — генерация и монтаж)
docs/      методика скаутинга + профиль бренда, карта мостов, арт-гайд
           (нуар-формула, словарь метафор), школа промптов
sources.example.json  шаблон пула источников (скопируй в sources.json)
ideas/     сюда скаут складывает карточки-идеи (создаётся сам)
examples/  (пусто — сюда удобно класть готовые ролики-эталоны)
```
